# 🔗 Backlink Buddy

A beginner-friendly 5-page website for learning and practicing basic Off-Page SEO concepts.

## Pages
- `index.html` — Home
- `learn.html` — Off-Page SEO lessons
- `checker.html` — Simulated backlink checker
- `audit.html` — Interactive backlink audit
- `resources.html` — Checklist and SEO resources

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and folders in this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Important
The Backlink Checker uses generated demo values. It does not access a live backlink database. A production checker would require a real SEO API/backlink index and a backend.
